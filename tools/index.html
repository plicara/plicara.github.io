Tools

Python tools for checking generated output and running experiments. Start with an example, then inspect the source and the limits of the method.

regexbench

→

Check whether two regular expressions describe the same language, test generated patterns against examples, and screen for ReDoS risk.

pip install regexbench
regexbench eq '[0-9]+' '[0-9][0-9]*'

Supported syntax and limits · PyPI

python apache-2.0 on pypi

labloop

→

Run a command, measure the outcome, and keep or revert an agent’s proposed change. The trial record includes failed attempts. Inspired by autoresearch.

pip install labloop
